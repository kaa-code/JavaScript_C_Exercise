ログイン画面: ユーザーID、パスワードを入力させログイン成功時はホーム画面へ遷移、失敗時はそのまま再入力を促す(アカウントロックは一旦無し)。新規ユーザー登録画面へ遷移するボタンも用意。
新規ユーザー登録画面: ユーザーID(英数字、一意、ランダム提案)、表示名(10文字以内)、パスワード、メールアドレス(任意)、生年月日(任意)、性別(任意)を入力させ成功すればホーム画面に遷移、失敗すれば再入力を促す。
ホーム画面: ショッピングセクション、メニューボタンを配置。
ショッピングセクション: ショッピングタブの中に検索ボタン、各店舗エリアが並ぶ。
検索ボタン: 押すとボタンが大きくなり検索エリアが出る。検索エリアでは店舗選択(文字入力もできるプルダウン)、文字列検索、カテゴリなどを入力し検索確定ボタンを押すとページ遷移無く、下の各店舗エリアから検索対象に絞られる。
店舗エリア: 店舗タイトル(クリックで店舗ページに遷移)、商品カード(画像、商品名、値段、カテゴリ、あるなら在庫、カートに入れるボタン)が横一列に並ぶ。店舗カードはクリックで商品詳細がボトムシートで出る。
商品詳細ボトムシート: 商品名、商品画像、店舗名(店舗ページへ遷移できる)、商品説明、カテゴリ、値段、在庫数、お気に入りに入れるボタン、カートに入れるボタンがある。ボトムシートの外か×ボタンをクリック、ボトムシート上部にグラブを作りドラッグで閉じれる。
店舗ページ: 店舗名、店舗説明、店舗詳細情報、お気に入りに入れるボタン、検索ボタンと商品一覧(商品カード)。
メニューボタン: 画面左下に配置。メニューを出し、それぞれの画面に遷移。ホーム画面、カート画面、お気に入り画面、設定画面。
カート画面: 複数カートが縦に並び、カートを選択、カート内では商品一覧(商品画像、商品名、値段、個数)と商品総数、総額を表示。購入ボタンで購入画面に遷移。カート内の左上にカート一覧に戻れる。
購入画面: カート画面と大体同じ情報を表示し確認させる。確定ボタンで購入完了、カートを削除しホーム画面かカート画面か選んで遷移させる。
お気に入り画面: 商品一覧と検索機能。
設定画面: アカウント設定、セキュリティ設定(パスワードの変更)、UI設定、ログアウトなど。アカウント設定でアカウント画面に遷移。ログアウトでログアウトしログイン画面に遷移。
アカウント画面: アカウントの表示名、その他項目を編集可能(ユーザーID以外)。アカウント削除ボタン(2回くらい確認する)。


# 実装にあたって
## HTML
- 一般的に望ましいとされるような綺麗な構造、記述にする。
- タグを正しく使用する。
## CSS
- 一般的に望ましいとされるような綺麗な構造、記述にする。
- 保守性、可読性を高くする。
## JavaScript
- クリーンコード思想に則りコーディングを行う。
- 部品、処理が冗長にならないように分離し、コード全体で汎用性を持たせる。
- 全ての部品、処理で細かいパラメータを持たせ自由度を高くする。
- 変数名、関数名などもクリーンコード思想に則り命名する。
- 保守性、可読性を高くする。
- JavaScriptの関数には以下の例のフォーマットでコメントを記述する。
  ```
  // 関数: 2つの数値の和を求める。
  // 引数: a(Number): 1つ目のオペランド, b(Number): 2つ目のオペランド
  // 戻り値: aとbの和 (a + b)
  function sum(a, b) {
    return a + b;
  }
  ```
